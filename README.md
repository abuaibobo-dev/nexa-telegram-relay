# NEXA Telegram Relay

独立 Android 频道采集与复制转发工具。所有运行规则、断点、统计和密钥保存在本机，不依赖电脑或自建服务器。当前版本为 1.1.0。

## 使用前准备

1. 在 `my.telegram.org` 创建应用，取得 Telegram API ID 和 API Hash。
2. 安装 APK 后，在“设置中心”保存 API 信息，再到“频道管理”登录 Telegram。
3. 同步频道，为频道标注“来源”或“目标”；目标频道需要当前账号具备发消息权限。
4. 创建规则并启动采集服务。首次从来源频道最早可访问的消息开始，之后使用加密断点继续。

## 已实现

- 多来源、多目标频道规则；已绑定来源不会重复出现。
- 图片、视频、图片＋视频、完整媒体组或全部内容采集。
- 整组保留、组内筛选、整组跳过。
- 排除关键词、暂停/恢复、清空断点、日志与运行总览。
- 复制发送，不显示转发来源；不绕过 Telegram 的内容保护。
- 原生前台服务与后台调度、进程恢复、随机间隔、FloodWait 自动退避、永久失败规则自动暂停。
- 原生持久统计与最近事件；页面重开后仍能恢复运行状态。
- DeepSeek 只用于只读维护分析，不提供聊天入口，也不自动执行高风险操作。
- 可选 SOCKS5/HTTP 代理、运行时段、每日上限和连续失败熔断。
- 支持文本、文件、GIF、音频、语音以及媒体说明保留/删除。
- 配置导入导出、日志复制/清空、全局暂停恢复和紧急停止。
- 极简黑白灰界面；仅错误、阻断和危险操作使用红色。

## 注意

- 仅处理你有权采集和发布的内容，并遵守 Telegram 条款及当地法律。
- 当前 release APK 使用测试签名，适合个人侧载测试；正式发布前应换成你自己的长期签名证书。
- Android 可能限制后台任务。持续运行时请允许通知，并关闭系统对本应用的省电限制。
